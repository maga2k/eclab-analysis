# EC-Lab Electrochemical Cells and Supercapacitors Data Analysis

Python-based data processing and automated plotting tool for electrochemical cycling data generated by Bio-Logic EC-Lab.

---

# Overview


This repository contains scripts and tools designed to parse, process, and visualize experimental data obtained from lithium-ion cells and super capacitors tested via EC-Lab. It automates the extraction of key electrochemical metrics (such as voltage and current profiles, capacity, coulomb efficiency, practical energy, and average power) and geenerates publication-ready figures for technical reports and academic papers. 

---

# Features

* Parse .mpr EC-Lab data files by using Galvani library

* Automated data processing: parses raw experimental exports and cleans column names

* Voltage & Current Tims-Series: generates synchronized multi-panel overviews of testing procedures

* Discharge & Charge profiles: compares voltage behavior against time and discharged capacity across multiple C-rates

* Efficiency & Energy calculations: computes coulomb efficiency, practical delivered energy, and average power per cycle

* Ragone plot

# Installation

Clone the repository:

git clone https://github.com/your-username/eclab-analysis.git

cd eclab-analysis

Install dependencies:

pip install -r requirements.txt

---

# Usage

Place your processed dataset inside the project workflow, and run the script:

python src/main.py

This will:

* ask if you are analyzing Li-ion cells or supercapacitors, and then you will choose your file(s)
* perform the analysis
* generate plots
* save results in the output folder


---

# Data Processing Workflow

1. Load raw EC-Lab data file
2. Clean and format the dataset
3. Compute electrochemical metrics
4. Generate plots
5. Save processed data and figures

---

# Motivation

Electrochemical experiments often generate large datasets that require systematic processing and visualization.

This project aims to:

* improve reproducibility
* automate repetitive analysis tasks
* create reusable research tools
* build practical data analysis skills for electrochemical energy storage systems
